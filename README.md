# バイトのシフト作成（試作版）

Googleフォームで集めた「30分ごとの出勤できる時間」を読み込み、時間帯ごとの必要人数を満たすシフトを自動で作ります。
自動作成には Google の OR-Tools（CP-SAT）を使っています。画面とシステムの作りは [timetable_creator](https://github.com/hagemarudon/timetable_creator) にそろえています。

## 使い方

```bash
pip install -r requirements.txt
streamlit run app.py              # 画面で使う（http://localhost:8501）
python cli.py 回答.csv 出力.xlsx    # 画面なしで使う
python make_sample.py             # サンプルの回答を作り直す
python -m pytest tests            # テスト
```

## 流れ

1. [google_forms/README.md](google_forms/README.md) の手順で、期間と営業時間に合わせたフォームを作り、スタッフに送る
2. 回答が集まったら、アプリで回答を読み込む
   - 回答のスプレッドシートを「ファイル → ダウンロード → カンマ区切り形式（.csv）」か「Microsoft Excel」で保存してアップロード
   - または下の「回答を自動で読み込む」を設定すれば、アプリを開くだけで最新の回答を読む
3. 左側で期間・祝日・勤務の長さ・必要人数を確かめ、「シフトを作る」を押す
4. 「シフト表」「日別」「個人別」「集計」「人数不足」で確かめ、Excelでダウンロードする

## 入力（フォームの回答）

Googleフォームの回答シート（`フォームの回答 1`）をそのまま読みます。

| 列 | 内容 |
| --- | --- |
| 氏名 | 必須。同じ氏名で2回以上答えたときは最後の回答を使う（空白の有無は区別しない） |
| 出勤できる時間 [10:00-10:30] | チェックボックス（グリッド）の回答。値は「11/16(月), 11/17(火)」のように選んだ日付 |
| 期間中に入れる最大日数（任意） | 見出しに「最大日数」を含む列 |
| 期間中の希望勤務時間（任意） | 見出しに「希望勤務時間」を含む列 |
| 備考（任意） | 見出しに「備考」か「要望」を含む列（アプリは読むだけで使わない） |

グリッドは、行と列のどちらか一方が時刻（`10:00` `10:00-10:30` `10時〜11時`）、もう一方が日付（`11/16(月)`）なら向きはどちらでも読めます。
`10:00-11:00` のように1時間ずつ聞いた場合も、その時間にかかる30分の枠すべてを出勤できるとみなします。
日付に年がなければ、回答のタイムスタンプに一番近い年にします（12月に1月分を聞いても大丈夫です）。

見本は `sample/フォーム回答サンプル.csv`（架空のスタッフ20人・2週間）です。

画面の「スタッフ」で、責任者の印・最大日数・希望時間・上限時間を人ごとに直せます。

## 守るルール

必須（必ず守る）
- 出勤できる時間にだけ入れる。営業時間（必要人数が1人以上の時間）の外には入れない
- 1日に入るのは1回（連続した勤務）まで。長さは「最短」以上「延長上限」以下
- 最大日数・上限時間を超えない

優先（点数で調整、重みは `config.toml` の `[weights]`）
1. 必要人数の不足をなくす（最優先）
2. 責任者を入れる（「営業中はいつも責任者を1人以上入れる」をオンにしたとき）
3. 1回の勤務は「原則」の長さ（初期値 2時間）まで。超えるのは、人数が足りない時間帯をうめるときだけ
4. 人数を多くしすぎない / 勤務時間を人によって偏らせない / 希望勤務時間に近づける / 出勤日を少なく

足りない時間帯は「人数不足」に、その時間に出勤できる人数と一緒に出します。

## 条件の入力

| 項目 | 内容 |
| --- | --- |
| 期間 | 回答に出てくる日付から自動で入る。短くしてもよい |
| 祝日として扱う日 | 「平日」「土日祝」「日祝」の当てはめに使う |
| 1回の勤務（時間） | 最短・原則・延長上限 |
| 必要人数 | 曜日・開始・終了・人数の表。下の行ほど優先（同じ時間帯は下の行で上書き）。曜日は `毎日` `平日` `土` `日祝` `土日祝` `月水金` `11/23` など |
| 責任者 | 営業中はいつも責任者を1人以上入れるか |
| 優先条件の重み | 上の優先ルールをどれだけ重視するか |

「この条件を既定にする」を押すと `config.local.toml` に保存され、次回から最初に入ります（Gitで管理しません）。`config.toml` は全員共通の初期値です。

## 出力

| シート | 内容 |
| --- | --- |
| シフト表 | スタッフ×日付。セルは「10:00-12:00」。右端に日数と合計時間。土曜は青、日祝は赤の見出し |
| 日別 | 日ごとに、人×30分のマスを塗った表。延長した勤務はオレンジ、下の行は配置人数／必要人数（不足は赤） |
| 個人別 | 1勤務1行（氏名・日付・開始・終了・時間・延長） |
| 集計 | 人ごとの出勤日数・合計時間・延長した日・出勤できる時間 |
| 人数不足 | 足りない時間帯 |

Googleスプレッドシートから読んだときは、元のスプレッドシートに「シフト表」「個人別」「集計」「人数不足」シートを書き込めます。

## 回答を自動で読み込む（サービスアカウント）

回答のスプレッドシートを専用の「サービスアカウント」に共有しておくと、アプリを開くだけで最新の回答を読み込みます（使う人のログインは不要、回答は非公開のまま）。
シフトを作ったあと「元のGoogleスプレッドシートに書き込む」で、同じスプレッドシートに「シフト表」などのシートを書き込めます。

設定（最初に1回）

1. [Google Cloud コンソール](https://console.cloud.google.com/) でプロジェクトを作る
2. 「APIとサービス → ライブラリ」で **Google Sheets API** を有効にする
3. 「IAMと管理 → サービスアカウント → サービスアカウントを作成」で作る（名前は例えば `shift-reader`。ロールは付けなくてよい）
4. できたサービスアカウントを開き「キー → 鍵を追加 → 新しい鍵を作成 → JSON」でファイルをダウンロードする
   （このファイルは合鍵です。人に送ったり GitHub に上げたりしないでください）
5. 回答のスプレッドシートの「共有」で、JSONの中の `client_email`（`…@….iam.gserviceaccount.com`）を **編集者** で追加する
6. アプリに秘密の設定を入れる
   - Streamlit Community Cloud：アプリの「Settings → Secrets」
   - 手元：`.streamlit/secrets.toml`（Gitで管理しない）

ダウンロードしたJSONの中身を `'''` と `'''` の間にそのまま貼り、下に回答のスプレッドシートのURLを書きます（`gcp_service_account_json` は `[responses]` より上に置いてください）。

```toml
gcp_service_account_json = '''
{
  "type": "service_account",
  ...
}
'''

[responses]
url = "https://docs.google.com/spreadsheets/d/xxxx/edit"
```

`[responses]` の `url` を入れておくと、アプリを開いたときにそのスプレッドシートを読み込みます。画面でURLを変えて別のシートを読むこともできます。
学校や会社の Google アカウントでは、管理者の設定で鍵（JSON）を作れないことがあります。その場合は個人の Google アカウントで作ってください。

「ファイル → 共有 → ウェブに公開」で CSV にしたURL（`…/pub?…output=csv`）を `url` に入れれば、サービスアカウントなしでも読めます。ただしURLを知っている人は誰でも回答を見られます。

## Googleスプレッドシートから読む（Googleログイン）

サービスアカウントを設定していないときは、使う人がそれぞれGoogleでログインして読むこともできます。設定は timetable_creator と同じです。
Google Cloud で Google Sheets API を有効にし、OAuth クライアント（ウェブ アプリケーション、リダイレクト URI はアプリのURL）を作って、secrets に書きます。

```toml
[google_oauth]
client_id = "xxxx.apps.googleusercontent.com"
client_secret = "xxxx"
redirect_uri = "http://localhost:8501"
```

## 構成

- `shift/loader.py` 設定とフォームの回答（CSV・Excel・スプレッドシート）の読み込み、必要人数の計算
- `shift/solver.py` シフトの自動作成（OR-Tools）
- `shift/output.py` 表の作成と Excel への書き出し
- `shift/google_sheets.py` スプレッドシートの読み書き（サービスアカウント・Googleログイン・ウェブに公開したCSV）
- `shift/settings_io.py` 画面で入力した条件の保存
- `google_forms/forms.gs` 出勤できる時間を聞く Google フォームを作る（Apps Script）
- `app.py` 画面（Streamlit）／ `cli.py` コマンドライン版
