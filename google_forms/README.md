# 出勤できる時間を集める Google フォーム

期間の日付ごとに、30分刻みで出勤できる時間を聞くフォームを作る Google Apps Script です（`forms.gs`）。

| 質問 | 形式 |
| --- | --- |
| 氏名 | プルダウン（必須）。選択肢は「名簿」シートの氏名 |
| 期間中に入れる最大日数（任意） | 記述（整数） |
| 期間中の希望勤務時間（任意） | 記述（数字） |
| 出勤できる時間（11/16〜11/22） | チェックボックス（グリッド）。行が時刻（10:00-10:30 …）、列がその週の日付（11/16(月) …）。1週間ごとに1問 |
| 備考（任意） | 段落 |

## 準備（期間ごとに1回）

1. Google ドライブで新しいスプレッドシートを作る（例「シフト希望 11月後半」）。シートを1つ追加して名前を「名簿」にし、A1に「氏名」、A2から下にスタッフの氏名を1人1行で書く
2. メニュー「拡張機能 → Apps Script」を開き、`コード.gs` の中身を消して `forms.gs` を丸ごと貼り付け、保存する
3. 上の方の `CONFIG` を直す
   - `shop`：フォームの題名に入る店名
   - `startDate` `endDate`：シフトの期間（`2026-11-16` の形）
   - `openTime` `closeTime`：聞く時間帯。アプリの必要人数の時間帯を含むようにする
   - `slotMinutes`：刻み（分、ふつうは30）
   - `closedWeekdays`：定休日の曜日（例 `['水']`）
4. 関数の選択欄で `フォームを作る` を選んで「実行」。初回は Google の許可画面が出るので許可する
   （「名簿」シートが無い・空のときは、空の「名簿」シートができて止まるので、氏名を書いてからもう一度実行する）
   （「このアプリは確認されていません」と出たら「詳細 → 〜（安全ではないページ）に移動」）
5. 表示された回答用のURLをスタッフに送る

## 名簿

フォームの氏名は、スプレッドシートの「名簿」シート（A列の2行目から）に書いた氏名から選ぶプルダウンです。
自由に書いてもらうと「山田」「山田太郎」のように同じ人が別の名前になり、アプリで別の人として扱われるので、名簿から選んでもらいます。
アプリの「日ごとの指定」の表にも、この氏名がそのまま並びます。

- 人が増えた・名前を直したときは、名簿を直してからメニュー「シフト → 名簿をフォームに反映」（または関数 `名簿をフォームに反映`）を実行する。フォームの選択肢が名簿どおりになる
- **前のスクリプトで作った、氏名が記述式のフォーム**も、`forms.gs` を貼り直して（`CONFIG` は今のフォームに合わせたまま）名簿を書き、`名簿をフォームに反映` を実行すると、同じ位置のプルダウンに置きかわる。それまでの回答はそのまま使える（回答のシートに「氏名」の列がもう1つ増えるが、アプリは両方の列を読む）
- 名簿の名前が重なっている（空白だけ違うなど）ときは、最初の1つだけを選択肢にする

## 回答をシフトに使う

アプリで、このスプレッドシートのURLを読み込みます（Googleログインを設定していないときは「ファイル → ダウンロード → カンマ区切り形式（.csv）」で保存してアップロード）。

質問を手で直すときは、見出しの「氏名」「最大日数」「希望勤務時間」「備考」の言葉と、グリッドの行・列の書き方（`10:00-10:30` と `11/16(月)`）を変えないでください。

## アプリに回答を自動で渡す（responses_api.gs）

CSVのダウンロードとアップロードをしなくても、アプリが最新の回答を読めるようにします。Google Cloud の設定はいりません。

1. 回答が集まるスプレッドシートで「拡張機能 → Apps Script」を開く
2. 左の「ファイル」の「＋ → スクリプト」でファイルを1つ追加し、`responses_api.gs` を丸ごと貼り付けて保存する
3. 関数の選択欄で `合言葉を作る` を選んで「実行」する（初回は許可画面が出るので許可する）。合言葉が表示されるので控えておく
4. 右上の「デプロイ → 新しいデプロイ」で、種類の歯車から「ウェブアプリ」を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 「デプロイ」を押すと「ウェブアプリのURL」（`https://script.google.com/macros/s/…/exec`）が出るのでコピーする
6. そのURLの後ろに `?key=合言葉` を付けて、アプリの Secrets に入れる

```toml
[responses]
url = "https://script.google.com/macros/s/…/exec?key=合言葉"
```

- 「アクセスできるユーザー：全員」でも、合言葉が合わなければ回答は返しません。URLは人に教えないでください
- 合言葉が漏れたときは `合言葉を作る` をもう一度実行すると、前の合言葉は使えなくなります（Secrets の key も新しくする）
- スクリプトを直したときは「デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン：新しいバージョン」で更新する（URLは変わらない）
- アプリの「元のGoogleスプレッドシートに書き込む」を押すと、このスプレッドシートに「シフト表」「個人別」「集計」「人数不足」シートを書き込みます（回答のシートは上書きしません）
