# 出勤できる時間を集める Google フォーム

期間の日付ごとに、30分刻みで出勤できる時間を聞くフォームを作る Google Apps Script です（`forms.gs`）。

| 質問 | 形式 |
| --- | --- |
| 氏名 | 記述（必須） |
| 期間中に入れる最大日数（任意） | 記述（整数） |
| 期間中の希望勤務時間（任意） | 記述（数字） |
| 出勤できる時間（11/16〜11/22） | チェックボックス（グリッド）。行が時刻（10:00-10:30 …）、列がその週の日付（11/16(月) …）。1週間ごとに1問 |
| 備考（任意） | 段落 |

## 準備（期間ごとに1回）

1. Google ドライブで新しいスプレッドシートを作る（例「シフト希望 11月後半」）
2. メニュー「拡張機能 → Apps Script」を開き、`コード.gs` の中身を消して `forms.gs` を丸ごと貼り付け、保存する
3. 上の方の `CONFIG` を直す
   - `shop`：フォームの題名に入る店名
   - `startDate` `endDate`：シフトの期間（`2026-11-16` の形）
   - `openTime` `closeTime`：聞く時間帯。アプリの必要人数の時間帯を含むようにする
   - `slotMinutes`：刻み（分、ふつうは30）
   - `closedWeekdays`：定休日の曜日（例 `['水']`）
4. 関数の選択欄で `フォームを作る` を選んで「実行」。初回は Google の許可画面が出るので許可する
   （「このアプリは確認されていません」と出たら「詳細 → 〜（安全ではないページ）に移動」）
5. 表示された回答用のURLをスタッフに送る

## 回答をシフトに使う

アプリで、このスプレッドシートのURLを読み込みます（Googleログインを設定していないときは「ファイル → ダウンロード → カンマ区切り形式（.csv）」で保存してアップロード）。

質問を手で直すときは、見出しの「氏名」「最大日数」「希望勤務時間」「備考」の言葉と、グリッドの行・列の書き方（`10:00-10:30` と `11/16(月)`）を変えないでください。
