# NF2026 シフト作成

「NF2026 シフト希望調査」（Googleフォーム）の回答から、11/20〜11/23 のシフトを自動で作ります。
元の「バイトのシフト作成」（リポジトリ直下の `app.py`）はそのまま残し、その部品（`shift/`）を使った別のプログラムです。

## 使い方

```bash
pip install -r requirements.txt
streamlit run nf/app.py                  # 画面で使う（http://localhost:8501）
python nf/cli.py 回答.csv 出力.xlsx        # 画面なしで使う
python nf/make_sample.py                 # サンプルの回答（nf/sample/NF回答サンプル.csv）を作り直す
python -m pytest tests                   # テスト
```

1. 回答のスプレッドシートを「ファイル → ダウンロード → カンマ区切り形式（.csv）」で保存してアップロードする
   （Apps Script のウェブアプリなど、元のプログラムと同じ「回答を自動で読み込む」設定も使えます。リポジトリ直下の README を見てください）
2. 左側で、シフトを組む日・営業時間と必要人数・勤務の長さを確かめ、「シフトを作る」を押す
3. 「シフト表」「日別」「個人別」「集計」「人数不足・会計不在」で確かめ、Excelでダウンロードする

## フォームの読み方

| 質問 | 使い方 |
| --- | --- |
| Email（メールアドレス） | 同じ人が2回答えたときに見分ける（最後の回答を使う）。無ければ氏名で見分ける |
| 氏名 | 必須 |
| あなたは会計ですか？ | 「はい」の人を会計係にする（画面のスタッフの表で直せる） |
| 11/20〜11/23 の参加できない時間帯 | 選んだ時間帯には入れない。何も選ばない日は終日参加できる |

参加できない時間帯は、次のどの形でも読めます。

- 日ごとのチェックボックス：質問の題名に日付（`11/20(金)` `11月20日` など）があり、選択肢が時間帯
- チェックボックス（グリッド）：行か列の一方が日付、もう一方が時間帯
- 日ごとのセクションに、日付のない同じ題名の質問を置いた形：左から順に 11/20, 11/21, … に当てはめる

選択肢の時間帯は `10:00-11:00` `10:00〜11:00` `10時〜11時` `10-11時` `10時半〜` `〜11:00` `午前` `午後` `終日` などが読めます。
`10:00` のように時刻が1つだけの選択肢は、そこから1時間（画面で変えられます）とみなします。
少しでも参加できない時間にかかる30分の枠には入れません。読めなかった選択肢は「入力の確認」に出ます。
画面の「回答の読み取り結果」で、人ごと・日ごとにどう読んだかを確かめられます。

## 守るルール

必須（必ず守る）
- 参加できない時間帯には入れない。営業時間（必要人数が1人以上の時間）の外には入れない
- 1日に入るのは1回（連続した勤務）まで。長さは「最短」以上「延長上限」以下
- 最大日数・上限時間（画面のスタッフの表で入れたとき）を超えない
- **営業中はいつも会計係を1人以上入れる**（人数は画面で変えられます）。人数不足をなくすことよりも先に守ります
  - その時間に入れる会計係がいないなど、どうしても入れられない時間だけ「人数不足・会計不在」に「不在」と出します（その時間に出勤できる会計係の人数も出ます）

優先（点数で調整、重みは `nf/config.toml` の `[weights]`）
1. 必要人数の不足をなくす（最優先）
2. 1回の勤務は「原則」の長さ（初期値 2時間）まで。超えるのは、人数が足りない時間帯をうめるときだけ
3. 人数を多くしすぎない / 勤務時間を人によって偏らせない / 希望勤務時間に近づける / 出勤日を少なく

会計係を必ず入れるために、計算を2回します（1回目で会計係がいない時間を一番少なくし、2回目はそれを守ったまま残りを考える）。

## 設定（`nf/config.toml`）

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| `[period] dates` | 11/20〜11/23 | シフトを組む日 |
| `[period] holidays` | 11/23 | 祝日として扱う日（必要人数の「土日祝」などに使う） |
| `[[rules]]` | 毎日 10:00〜18:00・3人 | 必要人数（会計係もふくむ）。**仮の値なので、実際の営業時間・人数に直してください** |
| `[shift]` | 最短1時間・原則2時間・延長上限4時間 | 1回の勤務の長さ |
| `[accountant] min_people` | 1 | 営業中いつも入れる会計係の人数 |
| `[form] single_time_minutes` | 60 | 時刻が1つだけの選択肢の長さ（分） |

画面の「この条件を既定にする」を押すと `nf/config.local.toml` に保存され、次回から最初に入ります（Gitで管理しません）。

## 出力

元のプログラムと同じシートに、会計係の印を足しています。

| シート | 内容 |
| --- | --- |
| シフト表 | スタッフ×日付。左に「会計」の○ |
| 日別 | 日ごとに、人×30分のマス。会計係は名前に【会計】。下に配置／必要の人数と会計係の人数（いない枠は赤） |
| 個人別 | 1勤務1行 |
| 集計 | 人ごとの出勤日数・合計時間など |
| 人数不足 | 足りない時間帯と会計係がいない時間帯 |
| 回答の読み取り | 人ごと・日ごとの参加できない時間帯（読み取りの確認用） |

## 構成

- `nf/loader.py` NFのフォームの回答と設定の読み込み
- `nf/solver.py` シフトの自動作成（会計係を必ず入れる）
- `nf/output.py` 表と Excel（会計の印・会計不在）
- `nf/app.py` 画面（Streamlit）／ `nf/cli.py` コマンドライン版
- 読み込み（CSV・Excel・スプレッドシート）や表の作りは `shift/` をそのまま使っています
